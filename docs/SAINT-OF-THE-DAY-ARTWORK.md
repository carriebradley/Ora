# Saint of the Day: sourced artwork only (v457)

The Today card shows artwork only when an individual saint has an assigned, identity-matched image. **No generated portrait, generic silhouette, placeholder, or reserved image space** is displayed for saints without an image. If an assigned remote image fails to load, Ora removes the image and its art-source caption so the biography fills the card.

Curated examples (image matching is by saint identity, never automatic date/image search):
- Saint Clement of Rome: [Saint Paul Outside the Walls medallion](https://commons.wikimedia.org/wiki/File:4-St.Clement_I.jpg), public domain.
- Saint Catherine of Alexandria (Western and Byzantine): [fourteenth-century icon](https://commons.wikimedia.org/wiki/File:St.CatherineofAlexandria.jpg), public domain.
- Saint Andrew Dung-Lac: [Westerville parish stained glass photograph](https://commons.wikimedia.org/wiki/File:Saint_Paul_Catholic_Church_(Westerville,_Ohio)_-_stained_glass,_arcade,_Saint_Andrew_Dung_Lac.jpg), photographer Nheyob, CC BY-SA 3.0. The image depicts Andrew, not every companion martyr.
- Saint Martin of Tours: [Met Museum sculpture](https://commons.wikimedia.org/wiki/File:Saint_Martin_of_Tours_MET_DP144442.jpg), CC0.

Original specifically assigned saint images are retained. The artwork is optional and should not block offline biography reading. This change does not affect liturgical calendar assignments, source prayer text, local saved documents, bookmarks, or preferences.

Future additions should only use an actual, suitable, correctly attributed image of the saint. Until then, text-only cards are intentional.
