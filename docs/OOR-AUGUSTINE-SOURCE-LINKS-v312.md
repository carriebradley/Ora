# Historical source links for missing Office of Readings second readings — v312

Ora's Office of Readings contains an index of appointed second readings, many of which do not yet have a verified translation bundled for offline display. This update **does not invent or fill** any missing appointed text, nor does it increase the reported 105 available readings.

For five Augustine references, the missing-text panel offers a direct external link to the corresponding historical edition, while retaining the exact appointed reference and existing search fallback.

| Appointed indexed reference | Open historical source edition |
| --- | --- |
| Augustine, On Psalm 127, 2 | https://www.newadvent.org/fathers/1801127.htm |
| Augustine, On Psalm 140, 4–6 | https://www.newadvent.org/fathers/1801140.htm |
| Augustine, On Psalm 148, 1–2 | https://www.newadvent.org/fathers/1801148.htm |
| Augustine, Confessions 9, 10–11 | https://www.newadvent.org/fathers/110109.htm |
| Augustine, Confessions 7, 10.18; 10, 27 | Book VII: https://www.newadvent.org/fathers/110107.htm and Book X: https://www.newadvent.org/fathers/110110.htm |

These New Advent pages contain public-domain historical English translations (J. E. Tweed for the psalm expositions; older English translation for Confessions). They are **not** the licensed contemporary Office of Readings translation. The exact liturgical extract and responsory are not promised to match the pages; the UI labels these as *source editions*, with a visible caveat. The search link remains available for other missing readings.

No scripture text, prayer book, indexed reference, source-calendar appointment, or licensed liturgical translation changes in this release.
