# Newton 2009 edition range safeguards

The Melkite reader applies PDF pages 30–96 only when the saved book has 159 pages and its page-two imprint contains both “FINAL DRAFT EDITION” and “COMMON ENGLISH TRANSLATION.” Other saved PDFs must not inherit this fixed range.

These tests guard the edition-specific extraction code against accidental broadening or loss of the range. They inspect the source implementation and do **not** constitute a page-by-page verification of the PDF. Full coverage still requires comparison against the original book's extracted and displayed prayers. The original saved book remains on the device.
