# Private Roman Missal text in the Mass view

A privately saved Roman Missal EPUB now displays prayer text directly in More → Sacred Liturgy → Mass, outside the collapsed file-management controls. The user selects their EPUB once per device. Book text, metadata and extracted prayers stay on the device; none are published with the app.

The reader preserves paragraphs, headings and internal book navigation as safe text and buttons. Scripture readings remain in the existing readings section. A unique normalized heading selects the day's prayers; matching handles ordinal spellings and named seasonal celebrations. Unmatched or ambiguous days explicitly require manual choice. This is section navigation, rather than a fully assembled Mass with every optional preface, Eucharistic Prayer, Common or vigil choice decided automatically. The book's own directions remain visible, and links to Commons and other sections remain usable.

When two sections match the same calendar title, the Mass preview explains that there is a choice and provides an **Open saved Missal** button. In the original reader, search for a Mass heading or an exact phrase and select a section. The reader returns to the last section you opened, including when offline. Book content and bookmarks are stored on this device. EPUB contents are cached in memory during the preview to avoid rereading the file for every date.

The [December 25, 2026 USCCB entry](https://bible.usccb.org/bible/readings/122526.cfm) distinguishes Christmas Mass forms. A fictional EPUB fixture tests two sections with the same Christmas title, one for the Vigil and one for Mass during the Day. The regression opens both, chooses one and checks the bookmark and original download after reopening. January 11 remains the ordinary-day example. This checks navigation and explicit choice. The [broader audit](https://github.com/carriebradley/Ora/issues/167) includes approved-edition wording and other Missal formats.
