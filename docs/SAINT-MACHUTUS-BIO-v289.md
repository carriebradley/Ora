# Saint Machutus (Malo) and Marian title safeguards (v289)

The November 15 Traditional/Sarum calendar names St. Machutus, also called St. Malo. Ora now shows a concise biography instead of an unsourced generic placeholder.

Biographical sources (not imported as verbatim text):
- https://www.vaticannews.va/en/saints/11/15/saint-malo.html
- https://www.biography.wales/article/s-MALO-SAN-0550.html
- https://www.newadvent.org/cathen/09503a.htm

The card uses two sentences, without a disputed exact death year. The separate source link gives the user more detail.

The same release fixes JavaScript word-boundary expressions distinguishing Marian feasts from individually named saints. Generic fallback cards are shortened to one sentence. Calendar facts, services, and prayer text are unchanged.
